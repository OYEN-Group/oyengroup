# Asset and Ownership Audit

**Project:** OYEN GROUP Corporate Website
**Date:** September 28, 2026
**Framework:** Next.js / React / Tailwind CSS

This document serves as a formal audit confirming the originality, licencing compliance, and ownership of the OYEN GROUP corporate website.

## 1. Custom Source Code Originality
The source code for the OYEN GROUP website has been 100% independently developed from scratch. No code, templates, or proprietary structural files were scraped, extracted, or copied from any external websites. Layouts and visual structures inspired by external references (e.g., IAC Group) were achieved strictly through bespoke coding of standard CSS and React patterns, ensuring complete structural originality.

## 2. Asset Licencing & Usage
- **Photography & Graphics:** All photographs, logos, and raster graphics utilized in the current build were supplied directly by the OYEN GROUP or uploaded into the development environment by the client. It is affirmed that these assets are authorized for commercial use by the OYEN GROUP.
- **Typography:** The website utilizes the fonts *Plus Jakarta Sans* and *Inter*. Both are open-source fonts available under the SIL Open Font License (OFL), which explicitly permits commercial use, modification, and distribution.

## 3. Third-Party Dependencies
All third-party software dependencies utilized in this project (including Next.js, React, Tailwind CSS, and Framer Motion) are open-source and operate under permissive commercial licences (primarily the MIT Licence). The development environment strictly adheres to these licencing terms, which allow for full commercial deployment without royalty obligations.

## 4. Ownership Rights
Upon completion and final deployment, the OYEN GROUP retains full ownership, copyright, and intellectual property rights to the bespoke source code, custom design implementations, and compiled application. The development process claims no proprietary hold over the final deliverables.

## 5. Non-Reproduction Guarantee
No proprietary code, images, graphics, text, or proprietary stylistic assets belonging to IAC Group or any other third-party company were reproduced, embedded, or utilized in the development of this website.
