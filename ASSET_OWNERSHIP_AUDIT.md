# Asset and Ownership Audit Declaration

**Project:** OYEN GROUP Corporate Website
**Date:** September 28, 2026
**Framework:** Next.js / React / Tailwind CSS

This document serves as a development and asset-compliance declaration, subject to verification by the OYEN GROUP, detailing the development practices and asset integration of the corporate website.

## 1. Custom Source Code Development Declaration
The bespoke source code for the OYEN GROUP website (specifically the React/Next.js components and Tailwind CSS implementation) was written to the client's specifications. While layouts and structural elements were inspired by client-provided references (e.g., IAC Group), no proprietary code or structural files were extracted or copied from those external websites. 

## 2. Asset Integration & Client Responsibility
- **Photography & Graphics:** All photographs, logos, and raster graphics integrated into this build were supplied directly by the client or uploaded into the development environment by the client. It is the responsibility of OYEN GROUP to verify and ensure that all provided imagery holds the appropriate commercial-use licenses or ownership rights prior to public deployment.
- **Typography:** The website utilizes the fonts *Plus Jakarta Sans* and *Inter*. Both are open-source fonts available under the SIL Open Font License (OFL), which permits commercial use and distribution.

## 3. Third-Party Dependencies
The bespoke code relies on underlying third-party open-source frameworks and libraries (including Next.js, React, Tailwind CSS, and Framer Motion). These third-party components operate under their respective permissive commercial licenses (primarily the MIT License). 

## 4. Ownership Rights Distinction
Ownership rights are distinguished as follows:
- **Bespoke Assets:** OYEN GROUP retains full ownership over the unique custom code written specifically for this project, as well as the proprietary logos, copy, and imagery provided by the client.
- **Open-Source Components:** The underlying third-party dependencies (Next.js, React, Tailwind) remain the intellectual property of their original creators and are utilized in this project strictly under the terms of their open-source licenses.

## 5. Non-Reproduction Statement
To the best of the development environment's parameters, no proprietary code, text, or specific graphic assets belonging to IAC Group or any other third-party reference company were embedded or directly reproduced in the creation of this project.
